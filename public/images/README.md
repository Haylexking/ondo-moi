# Images Directory

This directory contains all the images used in the Ondo MOI website.

## Structure

- `/executive-council/` - Images of Executive Council members
- `/commissioners/` - Images of Honourable Commissioners
- `/news/` - Images for news articles
- `/gallery/` - Images for the gallery section
- `/banners/` - Banner images for various pages
- `/logos/` - Logo files

## Image Guidelines

1. All images should be optimized for web (compressed)
2. Recommended formats: JPEG for photos, PNG for graphics with transparency, WebP where supported
3. Standard sizes:
   - Profile photos: 300x300px
   - Banner images: 1200x400px
   - News thumbnails: 400x300px
   - Gallery images: 800x600px
